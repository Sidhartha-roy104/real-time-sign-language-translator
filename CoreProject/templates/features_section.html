Project Features

Explore the key functionalities that make our Real-Time Sign Language Translator intelligent and interactive.

Real-Time Gesture Detection

Uses webcam with Mediapipe & OpenCV to capture hand gestures in real time.

Static & Dynamic Recognition

Supports both static alphabet signs and dynamic gesture sequences.

Text Translation

Instantly converts gestures into readable text on screen.

Speech Output

Converts the translated text into voice output for easier communication.

Custom Dataset Training

Lets users train new gestures to improve and expand model accuracy.

Multi-Language Support

Translates recognized text into various languages like English, Hindi, etc.

Accuracy Optimization

Hybrid CNN + LSTM model enhances accuracy and reduces error rates.

Live Prediction Visualization

Shows keypoints, gesture outlines, and prediction confidence live.

Cross-Platform Compatibility

Works seamlessly on Windows, Linux, and macOS platforms.

Offline Mode (Future)

Once the model is loaded, can run without internet connectivity.
